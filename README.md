# Hello World — Google Cloud Practice

A small cloud-development exercise created to learn the fundamentals of deploying and running an application workflow with Google Cloud Platform.

## Purpose

This repository is a lightweight cloud-learning project covering the basic developer workflow around:

- Cloud deployment
- Application packaging
- GCP services
- Git-based source management

## Status

**Learning / foundational cloud project.**

It is intentionally kept as a supporting repository rather than a flagship portfolio project.
